# Automation Assessor

**Open the tool:** https://rajneesh05-lab.github.io/automation-assessor/

Turn a client's process list or SOP into an automation assessment, for any industry, in your browser.

1. **Pick the industry.** It decides which process libraries are used.
2. **Read an SOP (optional).** Load Word, PDF or text and get the steps, who does them, the systems, the time per item and the best-fit technology.
3. **Enter the process list.** Picking the industry loads its processes; enter the client's FTE for each step they do. Or import the client's own files in any layout with **Import client format**. Several files can be read together, for example the process list from one and the volumes and FTE from another, and they are joined into one list. You can also paste rows from Excel, or import the input template.
4. **Get the assessment.** Click **Assess these files** (or **See the assessment**): the process list is minimized and the results open on the Summary tab. It also updates as you type:
   - Summary
   - Opportunities (Go / Maybe / No)
   - Baseline time and cost
   - Timeline
   - 3-year cost-benefit
   - Tool fit (RPA, document AI, generative AI, agentic AI, system fix)
   - RACI
   - Assumptions: how each number was worked out, line by line
5. **Download the Excel pack:** a workbook with live formulas. It also has the RAID log, controls and discovery questions.

**Libraries:** finance & accounting, banking, healthcare providers, health plans, retail, HR and payroll, contact center, and insurance by line: personal, commercial, life, annuities and group benefits. That's 188 processes. **Process library** downloads the full list.

**Privacy:** everything runs in your browser. The process list and documents are not uploaded anywhere. Your last inputs are kept in your own browser only.

**Important:** the libraries hold starter benchmarks written from general industry knowledge, not measured client data. Check them with an expert and the client's own numbers before using them in a priced proposal.

This repository holds only the built page (`index.html`).
